# Crazy Cylinder
This repository contains the code developed for the solution of problem #17 of the Iternational Physisicist Tournament "Crazy Cylinder". There´s two branches: the ipt branch has everything that was present on the project up to the moment of the competition, I'm still working on the main branch to develop the project further.

I used the FreeFem library to build a finite element Navier Stokes solver that could handle the moving meshes required for the nature of the penomenon being studied. The data analysis is donde on a jupyter notebook.
